# Buddy Aid UI Design System

The UI follows the supplied reference: bright light canvas, white rounded cards, soft pink borders, red→pink primary gradient, warm orange secondary actions, green success states, blue map accents, compact Inter-style typography, and shield-based Buddy Aid branding.

Primary: `#FF3C4F` → `#F31F71`
Warm secondary: `#FF9A1E` → `#FF3F56`
Text: `#1E2540`
Muted: `#7A829F`
Pink surface: `#FFF0F4`
Blue surface: `#EDF4FF`
Green surface: `#ECFFF4`

Main visual sections: Landing, Auth, User Dashboard, Emergency, Live Emergency Map, Safety Map, Report Problem, Community Reports, Profile/Settings, Emergency Contacts, Admin Dashboard, Reports Management, Support Tickets, Mobile previews.
